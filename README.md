# PepIntProt
Interactive Streamlit app for analyzing MD trajectories of peptide–protein complexes and APO simulations. 12 analyses (RMSD, RMSF, Rg, PCA, DSSP, FEL, eRMSF, ProLIF, and more), multi-replica support with cross-replica statistics, and AI-powered PDF reports via 6 providers (Databricks, Anthropic, Groq, OpenAI, Gemini, Ollama)
